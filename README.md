🚗 Car Price Prediction Using Machine Learning

📌 Overview

This project uses Machine Learning to predict car prices based on features such as manufacturing year, mileage, road tax, fuel efficiency (MPG), and engine size. 
The goal is to analyze vehicle data and build a model that estimates car prices.

🎯 Objectives

Perform data cleaning and preprocessing.
Explore and analyze car price data.
Train and evaluate regression models.
Identify the model that provides the best predictive performance.

🛠️ Technologies Used
Python
Pandas and NumPy
Matplotlib and Seaborn
Scikit-learn
Jupyter Notebook / VS Code

📊 Machine Learning Workflow

Data collection and exploration
Data cleaning and preprocessing
Feature selection and encoding
Model training
Model evaluation using R² score, MAE, and MSE

🤖 Models

The project may include regression algorithms such as:

Linear Regression
Decision Tree Regressor
Random Forest Regressor
